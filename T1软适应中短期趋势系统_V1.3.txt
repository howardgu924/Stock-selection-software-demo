T+1软适应中短期趋势系统 V1.3
版本日期：2026-07-14

一、系统定位

面向A股T+1交易制度，以5—20个交易日的中短期趋势为主要收益来源。
系统不硬切换趋势、震荡、下跌等策略，而是通过市场软适应机制调整买入门槛、新增仓位和账户风险。

系统结构：

前一日收盘数据
→ OpportunityScore：机会质量
→ MarketOverlay：市场软适应
→ RiskOverlay：个股与账户风险
→ ExecutionGate：盘中执行条件
→ PositionSizing：仓位分配
→ FillEngine：成交与T+1处理
→ ExitEngine：退出与调仓状态机


二、核心原则

1. OpportunityScore只使用前一交易日收盘后已经确定的数据。
2. MarketOverlay只调整门槛和风险额度，不改变个股机会分。
3. ExecutionGate只判断当天是否适合执行，不增加机会分。
4. RiskOverlay负责顶背离、ST、特殊交易状态、尾部风险和账户压力。
5. 回测必须按真实信息可用时点处理，避免未来数据泄漏。
6. 不允许因为实现顺序不同而产生不同仓位结果。
7. V1.2不主动加仓，只允许首次买入、持有、减仓、退出和退出后重新买入。
8. 回测期末不强制平仓，未卖持仓按期末收盘价计价。


三、OpportunityScore

OpportunityScore范围：0—100分。

组成：

1. 相对强度：40分
2. 趋势结构：35分
3. 方向性效率及变化：25分

Aroon、普通MACD和MACD背离不进入主机会分。


四、相对强度：40分

定义：

RS20 = 个股20日收益率 - 对应基准20日收益率
RS60 = 个股60日收益率 - 对应基准60日收益率

权重：

RS20：15分
RS60：25分

理由：

1. RS60用于提供稳定的中期趋势背景，因此权重更高。
2. RS20用于识别近期改善和趋势加速。
3. 当有效自选股数量不少于10只时，可加入自选股内部横向排名。
4. 当有效自选股少于10只时，仅使用相对基准表现，不使用池内排名计分。

建议映射要求：

每个RS因子必须明确：
- 输入值
- 上下界
- 映射函数
- 截断规则
- 缺失值处理
- 并列排名处理

正式编码前不得使用“较强”“明显改善”等模糊描述。


五、趋势结构：35分

1. 收盘价相对MA20：10分

定义：

X1 = (Close - MA20) / ATR20

Score1 = 10 × clip((X1 + 1) / 2, 0, 1)

对应：

X1 ≤ -1：0分
X1 = 0：5分
X1 ≥ 1：10分

2. MA20相对MA60：15分

定义：

X2 = (MA20 - MA60) / ATR20

Score2 = 15 × clip((X2 + 1) / 2.5, 0, 1)

对应：

X2 ≤ -1：0分
X2 = 0：6分
X2 ≥ 1.5：15分

3. MA60近10日斜率：10分

定义：

X3 = (MA60_t - MA60_t-10) / ATR20

Score3 = 10 × clip((X3 + 0.5) / 1.5, 0, 1)

对应：

X3 ≤ -0.5：0分
X3 = 0：约3.33分
X3 ≥ 1：10分

其中：

clip(x, 0, 1) = min(1, max(0, x))


六、方向性效率及变化：25分

1. SignedER20：15分

定义：

SignedER20 =
(Close_t - Close_t-20)
/
Σ|Close_i - Close_i-1|

取值约为-1至1。

含义：

接近1：持续、顺畅上涨
接近0：震荡
接近-1：持续、顺畅下跌

2. 效率变化：10分

定义：

SignedERChange5 =
SignedER20_t - SignedER20_t-5

用于识别：

- 趋势效率是否继续改善
- 趋势是否从震荡转强
- 高效率趋势是否开始衰减

正式编码时必须明确映射函数，不允许使用“明显转弱”等模糊条件。


七、Aroon和普通MACD

Aroon继续计算：

- Aroon Up
- Aroon Down
- Aroon Oscillator

普通MACD继续计算：

- DIF
- DEA
- MACD柱体
- 柱体变化
- 零轴位置

但两者均不进入OpportunityScore。

原因：

1. 与RS、均线结构和趋势效率高度相关。
2. DIF > DEA与MACD柱 > 0方向上等价，不能重复计分。
3. 先保留为诊断字段，待因子删减测试证明有独立增益后再考虑加入。


八、MACD背离

背离属于RiskOverlay，不进入OpportunityScore，也不进入ExecutionGate。

1. 摆动点确认

使用左右各3根日K线确认摆动高低点。

必须记录：

- pivot_date
- confirmed_date
- first_usable_date

例如：

周一形成高点
周四收盘后完成确认
周五最早可用于交易判断

回测不得把背离信号回填到pivot_date用于交易。

2. 普通顶背离

条件：

第二个价格高点高于第一个价格高点
第二个高点对应DIF低于第一个高点

处理：

RiskMultiplier = 0.75

不再同时触发ExecutionGate的HALF，避免重复处罚。

3. 强顶背离

在普通顶背离基础上，同时满足：

- 第二个价格高点至少高出0.5 ATR
- 第二个高点对应MACD柱峰值更低

处理：

- 禁止新买入
- 禁止加仓
- 已有持仓进入高风险观察

只有同时出现结构破坏、SignedER明显转弱或ATR风险线触发时，才减仓或退出。

4. 底背离

底背离不直接加分。

只设置：

recovery_watch = true

只有同时满足：

- 重新站上MA20
- RS20改善
- SignedER20转正

才恢复为普通候选。


九、MarketOverlay

1. 市场指数

沪深300：40%
中证1000：40%
创业板指：20%

2. 单个指数环境分

收盘价相对MA20：30%
MA20相对MA60：40%
MA60近10日斜率：30%

3. 平滑

SmoothedMarketScore =
RawMarketScore的5日EMA

理由：

- 过滤单日噪声
- 保留对中短期风险变化的反应速度

4. 买入门槛

设：

M = SmoothedMarketScore / 100

EntryThreshold = 70 + 8 × (1 - M)

示例：

市场分100：门槛70
市场分80：门槛71.6
市场分60：门槛73.2
市场分40：门槛74.8
市场分20：门槛76.4

当SmoothedMarketScore < 20时，暂停新增仓位。

5. 总仓位上限

ExposureCap = 90% × M

最高90%的原因：

最多6只 × 单股最高15% = 90%

普通市场变化下：

- 立即限制新仓
- 不机械卖出已有强势持仓
- 总仓位上限单日最多下降10个百分点


十、EmergencyMarketGate

用于处理5日EMA无法及时反映的突发风险。

对三个宽基指数分别计算：

Shock_i =
(IndexPrice_10:00 / PreviousClose - 1)
/
(ATR20_i / PreviousClose)

1. 一级风险

三个指数中至少两个满足：

Shock ≤ -0.8

处理：

- 当天所有新仓REJECT
- 已有持仓不因该条件机械卖出

2. 二级极端风险

至少两个指数满足：

Shock ≤ -1.2

处理：

- 取消总仓位单日最多下降10个百分点的限制
- 允许当日快速降低可卖持仓
- 优先处理OpportunityScore最低的持仓
- 单日快速降险目标最多下降30个百分点

阈值需要测试：

0.8 / 1.0 / 1.2 ATR


十一、RiskOverlay硬阻断

以下情况不允许新买入：

- ST、*ST
- 退市整理
- 停牌
- 数据异常
- 无涨跌幅限制的特殊交易日
- 强顶背离
- 股票代码或交易状态无法确认

重大资产重组等事件只有在存在可靠、历史时点可用的公告数据时才进行阻断。


十二、ExecutionGate

判断时点：10:00
最早成交时点：10:05

输出：

- PASS
- HALF
- REJECT

ExecutionGate不改变OpportunityScore。

1. REJECT条件

任意满足一项：

- 停牌
- 涨停或无法确认可成交状态
- 10点价格高于MA20超过2 ATR
- 10点价格低于MA20超过1 ATR
- 早盘高点至10点回撤超过0.75 ATR
- 高开后跌破VWAP超过0.5 ATR
- 数据缺失或异常
- EmergencyMarketGate触发一级或二级风险

2. HALF条件

未触发REJECT，但满足任意一项：

- 价格高于MA20 1.5—2 ATR
- 价格低于早盘VWAP 0.25—0.5 ATR
- 早盘最大回撤0.5—0.75 ATR

处理：

目标仓位 × 0.5

普通顶背离不再进入HALF。


十三、简化成交原则

V1.3不再计算成交容量、参与率、买卖价差、滑点或部分成交。

成交采用“指定执行时点直接按该时点价格成交”的研究假设：

- 条件满足：整笔成交
- 条件不满足：整笔失败
- 不进行追价
- 不模拟排队
- 不模拟部分成交
- 不使用执行K线最终成交量判断是否成交

该简化适合当前研究基准系统，优点是：

1. 规则唯一，容易实现和核对。
2. 不会因为容量模型或盘口假设引入额外参数。
3. 便于先检验选股、市场覆盖和退出逻辑本身是否有效。

该成交模型会比真实交易略乐观，因此回测报告必须明确标记：

simplified_direct_fill = true

成交失败只考虑：

- 停牌
- 买入时涨停
- 卖出时跌停
- 执行价格缺失或异常
- T+1可卖数量不足
- 现金、持仓或交易单位不满足要求


十四、PositionSizing

1. 独立风险仓位

RawWeight_i =
min(
15%,
0.5% / EffectiveRiskPct_i
)

2. 正常风险距离

NormalRiskPct =
2 × EntryATR20 / EntryPrice

EntryATR20在入场时冻结。

3. T+1首次可卖尾部损失

对历史每个可模拟买入日计算：

假设当日10:05买入
→ 下一交易日第一个实际可卖时点
→ 相对买入价的收益

T1Loss_q =
首次可卖收益5%分位的绝对值

观察窗口：

- 优先252日
- 最低120个有效样本

样本不足时，使用对应板块或宽基样本的尾部风险估计。

4. 有效风险距离

EffectiveRiskPct =
max(
NormalRiskPct,
T1Loss_q
)

5. 单股风险预算

每只股票计划风险预算：
账户净值的0.5%

理由：

最多6只时，理想计划风险约为3%。

0.5%不是最大损失承诺，实际T+1、跳空和跌停可能造成更大损失。


十五、账户压力测试

PortfolioStressLoss =
Σ Weight_i × T1Loss_q_i

默认要求：

PortfolioStressLoss ≤ 账户净值的5%

超过5%时，所有目标仓位按比例缩小。

同时输出以下压力场景：

- 单只股票一个跌停板对账户的影响
- 两只最高相关持仓同时发生尾部损失
- 一只股票连续两个交易日无法正常退出


十六、行业与相关性约束

1. 行业约束

单一行业最高仓位：30%

若某行业目标仓位合计超过30%，该行业全部股票按比例缩放至30%。

2. 相关性约束

使用近60日收益相关系数。

候选按OpportunityScore从高到低处理：

- 与1只已选股票相关系数 ≥ 0.80：RawWeight × 0.5
- 与2只已选股票均 ≥ 0.80：拒绝该候选

测试范围：

0.75 / 0.80 / 0.85


十七、统一仓位分配顺序

1. 所有候选同时计算RawWeight
2. 应用RiskMultiplier
3. 应用ExecutionGate乘数
4. 应用相关性约束
5. 应用行业30%约束
6. 应用ExposureCap总仓位约束
7. 应用PortfolioStressLoss压力约束
8. 按交易规则进行手数取整
9. 剩余现金不再次分配

不得按数据库返回顺序逐只消耗剩余额度。


十八、持仓与迟滞

1. 新买入

同时满足：

- OpportunityScore ≥ EntryThreshold
- 排名进入前6
- ExecutionGate为PASS或HALF
- RiskOverlay未阻断
- 账户、行业和压力测试允许

2. 持有门槛

HoldThreshold = EntryThreshold - 8

继续持有条件：

- OpportunityScore ≥ HoldThreshold
- 排名不低于第8
- 未触发硬退出

3. 替换条件

新候选比最弱持仓至少高8分，并且原持仓满足：

- 连续2日低于HoldThreshold
或
- 连续2日跌出前8

4. 新买入保护期

新买入后的前2个完整交易日：

- 不因轻微排名下降进行替换
- 硬止损和重大风险始终有效


十九、V1.2禁止主动加仓

同一股票建立初始仓位后：

- 不因分数上升自动加仓
- 不因市场仓位上限提高补仓
- 不重置初始止损
- 不重新计算平均风险预算

只允许：

- 首次买入
- 持有
- 减仓
- 全部退出
- 退出后重新买入


二十、止损

1. 初始止损

InitialStop =
EntryPrice - 2 × EntryATR20

EntryATR20在入场时冻结。

2. 移动止损

当浮盈达到1.5 ATR后启动。

CandidateStop_t =
HighestCloseSinceEntry - 2.5 × CurrentATR20

TrailingStop_t =
max(
TrailingStop_t-1,
CandidateStop_t
)

移动止损只能上移，不能下移。


二十一、ExitEngine动作优先级

每个执行时点按以下顺序处理：

1. PendingSell
2. 硬止损和硬退出
3. 账户级极端降险
4. 全部退出信号
5. 软减仓
6. 持仓替换
7. 普通持有
8. 新买入

高优先级动作处理后，同一股票当日不再执行低优先级动作。


二十二、软减仓

触发条件之一连续出现2个交易日：

- OpportunityScore < HoldThreshold
- 排名跌出前8
- 强顶背离后趋势进一步转弱
- 市场风险要求逐步降低账户仓位

处理：

减仓50%

一次软风险事件只允许减仓一次。

新增状态字段：

- soft_reduce_episode_id
- soft_reduce_applied

重置条件：

OpportunityScore重新高于HoldThreshold
且排名回到前8
连续3个交易日


二十三、全部退出

满足以下之一：

- OpportunityScore < EntryThreshold - 15，连续2日
- 排名跌出前10，连续3日
- 连续2日收盘低于MA60
- 单日收盘低于MA60超过1 ATR
- 触发初始止损
- 触发移动止损
- 强顶背离并出现结构破坏
- 账户级极端风险要求退出


二十四、最小调仓与重新买入

1. 最小调仓幅度

目标仓位变化至少达到：

账户净值的2个百分点

且取整后至少形成一个有效交易单位，才执行调仓。

2. 重新买入冷却期

完全退出后：

3个完整交易日内不重新买入同一股票

例外：

- OpportunityScore ≥ EntryThreshold + 5
- ExecutionGate = PASS
- 上次退出原因不是硬止损


二十五、T+1持仓状态

每只股票必须记录：

- PositionQty
- SellableQty
- TodayBoughtQty
- PendingSellQty
- AverageCost
- EntryATR20
- InitialStop
- TrailingStop
- HighestCloseSinceEntry

关系：

PositionQty =
SellableQty + TodayBoughtQty

每日开盘前：

SellableQty += 前一日TodayBoughtQty
TodayBoughtQty = 0

当天新买数量不能当天卖出。

若跌停无法卖出：

- 记录触发退出
- 记录委托失败
- 设置PendingSellQty
- 持仓继续计价
- 下一可交易时点继续尝试


二十六、FillEngine

1. 基本规则

成交价格直接使用预先规定的执行时间点价格，不增加滑点，不检查成交容量，不模拟部分成交。

若使用5分钟K线数据：

- 某时间点价格定义为该5分钟K线的开盘价
- 信号只能使用执行时间点之前已经完成的数据
- 不能在看完一根K线后再按同一根K线开盘价成交

2. 买入

信号确认：10:00
执行时间：10:05
成交价格：10:05这根5分钟K线开盘价

若10:05时：

- 股票停牌
- 股票涨停
- 执行价格缺失或异常
- 现金不足
- 买入数量不符合当日交易单位

则买入失败，当日不再追价。

3. 硬退出卖出

硬退出信号由某根已经完成的5分钟K线确认。

执行时间：下一根5分钟K线
成交价格：下一根5分钟K线开盘价

不能按触发止损的价格直接成交，也不能按用于产生信号的同一根K线开盘价成交。

4. 软退出、减仓和替换

评估时间：14:30
执行时间：14:35
成交价格：14:35这根5分钟K线开盘价

5. 成交失败

以下情况整笔失败：

- 停牌
- 买入时涨停
- 卖出时跌停
- 执行价格缺失或异常
- T+1可卖数量不足
- 现金不足
- 持仓不足
- 买入数量不符合交易单位

卖出失败时：

- 保留持仓
- 记录PendingSellQty
- 下一可交易执行点继续尝试

6. 费用

成交价格本身不增加滑点，但仍按交易日期计算：

- 佣金
- 最低佣金
- 卖出印花税
- 过户及结算相关费用


二十七、交易规则按日期管理

建立规则表：

- exchange
- board
- security_type
- effective_from
- effective_to
- buy_lot_size
- sell_lot_rule
- price_tick
- price_limit
- special_day_rule

不得永久写死：

- 所有股票都是100股整数手
- 所有股票最小变动单位都是0.01元
- 所有股票涨跌幅限制都是10%

费用也必须按交易日期读取：

- 佣金
- 最低佣金
- 卖出印花税
- 过户及结算费用


二十八、复权数据

同时保存：

1. 原始未复权OHLC
用于：

- 成交价格
- 涨跌停价
- 最小价格单位
- 交易规则
- 实际订单模拟

2. 历史时点调整序列
用于：

- 收益率
- 均线
- SignedER
- 技术指标连续计算

调整因子必须按当时已经发生的公司行为生成，不能直接将今天的调整结果作为唯一历史真相。


二十九、自选股快照

每天保存：

- snapshot_date
- watchlist_name
- symbol
- added_at
- removed_at
- source

支持两种模式：

1. 固定股票池研究
使用今天指定的股票研究历史表现，明确标记存在事后选择偏差。

2. 历史快照回测
使用每个交易日当时实际存在的自选股名单。


三十、持有期定义

5—20个交易日是预期持有期，不是强制退出期限。

不设置：

- 持有超过20日自动提高门槛
- 持有超过40日强制退出

需要统计：

- 持有期中位数
- 75%和90%分位
- 不同持有期区间收益
- 长期持仓对总利润的贡献


三十一、回测基准

必须同时运行：

1. 自选股等权持有
2. RS60排名前6等权
3. MA20 > MA60的简单趋势策略
4. 只使用OpportunityScore
5. 完整V1.2

主要比较：

- 年化收益
- 最大回撤
- 收益回撤比
- 换手率
- 净收益
- 费用
- 未成交率
- 跌停待卖损失

三十五、版本结论

V1.3相对V1.2的成交模型调整：

1. 删除成交容量、参与率和历史流动性估算。
2. 删除买入和卖出滑点计算。
3. 删除部分成交、排队和追价假设。
4. 买入信号在10:00确认，按10:05开盘价整笔成交。
5. 硬退出由已完成K线确认，按下一根5分钟K线开盘价整笔成交。
6. 软退出、减仓和替换在14:30确认，按14:35开盘价整笔成交。
7. 除涨跌停外，仍保留停牌、价格缺失、T+1、现金、持仓和交易单位检查。
8. 交易佣金、最低佣金、印花税及其他法定费用继续计算。
9. 回测结果必须标记为简化直接成交模型，不能把成交真实性等同于实盘。
10. 该版本优先检验策略逻辑本身，不让成交模型引入过多额外参数。
